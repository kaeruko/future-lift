# ミッション画面の素材

ユーザー指定の `kotohogu_quest_editable_parts` からコピーしたPNGです。原本は変更していません。

- デイリータブ、金・朱色のカード枠、空欄のタイトル帯、左右の角飾りを使用。
- カードに焼き込まれたコイン・宝石・星・「挑戦する」は、不透明なFlutterの内容領域で覆っています。外周の枠を活かし、実際のミッション名・社会貢献 +10・「できた！」を表示します。
- ウィークリー・メイン・イベントのタブや通貨機能は実装していません。

期間切り替え用の tab_selected.png / tab_unselected.png は、提供された kotohogu_quest_ui_assets の 09_tab_daily.png / 10_tab_weekly.png の未加工コピーです。文字部分はFlutter上で覆い、現在の期間名を重ねています。
