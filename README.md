# FutureLift

**自分をケアすることを、未来の誰かへの貢献に変える。**

FutureLift は、筋トレや日々のセルフケアを「自分の健康のため」だけではなく、**将来の介護負担や社会保障負担を軽くする社会貢献**として実感できるようにするアプリ構想です。

## 背景

高齢化が進む一方で、将来の介護人材不足や社会保障負担の増加が心配されています。

そこで FutureLift では、

> 将来、介護してくれる人が十分にいるとは限らない。
> それなら今から、自分で生活できる期間を少しでも長くする力を積み立てよう。
> その努力は、未来の誰かの負担を軽くすることにもつながる。

という考え方を出発点にしています。

介護が必要になること自体を否定したり、介護を受ける人を「負担」とみなしたりすることが目的ではありません。
病気や事故など、本人の努力では避けられないこともあります。

FutureLift が応援したいのは、**今できる範囲で、自立して暮らせる力を少しずつ残していくこと**です。

## コア体験

### スクワットすると、未来世代から拍手される

たとえばスクワットをすると、若者キャラクターたちが登場して拍手します。

```text
スクワット 10回！

👏👏👏👏👏
未来の介護負担をちょっと軽くしました！
社会貢献 +10
```

「運動できてえらい」だけではなく、

**あなたが元気でいてくれることは、未来の誰かの助けにもなる。**

という感覚を報酬にします。

将来的には、公的統計や研究に基づいて社会保障・介護費への影響を推計できる場合、

```text
未来の社会保障負担を推計 ○円ぶん軽くしました
```

のような演出も検討します。

ただし、根拠のない「スクワット1回 = ○円削減」のような数値は表示しません。金額を扱う場合は、推計モデル・前提・出典を明示します。

## なぜ「感謝」なのか

セルフケアはしばしば、

- 自分のために運動しましょう
- 自分を大切にしましょう
- 健康のために生活を整えましょう

と語られます。

でも、「自分のため」だけでは動きにくい人もいます。

FutureLift では、セルフケアを

**「未来の誰かを助ける行動」**

として捉え直します。

筋トレをした。
外に出た。
人と会った。
趣味を続けた。
歯や耳や目をケアした。

それらを「あなた自身のため」だけでなく、**将来の支援者・家族・現役世代・社会への小さな貢献**として褒めます。

## 目指すもの

FutureLift が扱いたいのは、単なる筋トレ記録ではありません。

目標は、年齢を重ねてもできるだけ長く、

- 自分の脚で動ける
- 自分で考えて決められる
- 食べる力を保てる
- 人とのつながりを持てる
- 趣味や役割を持てる
- 自分の生活を自分で回せる

という **「生活する力」** を積み立てることです。

## 現時点で重視しているテーマ

### 1. 筋力・身体活動

筋トレは中心機能にする予定です。
特に下肢筋力、歩行、バランス、日常的な身体活動を重視します。

### 2. 社会とのつながり

退職後にも残る友人関係やコミュニティ、定期的に人と会う機会を持つことを扱います。

### 3. 趣味・好奇心

新しいことを覚える、作る、遊ぶ、出かける、といった活動を応援します。

### 4. 生活機能を守る知識

認知機能、フレイル、転倒、栄養、口腔、聴力、視力、睡眠などについて、短い記事やマガジン形式で紹介する予定です。

「認知症を防げる」「要介護にならない」といった断定はせず、研究で分かっている範囲と分かっていない範囲を区別します。

## 想定ユーザー

主に、まだ自立して生活している現役世代を想定しています。

特に、

- 自分が高齢者になる頃の介護人材不足が気になる
- 家族に介護負担をかけたくない
- 老後もできるだけ自分で暮らしたい
- 「自分の健康のため」だけでは運動が続かない
- 人の役に立っている感覚があると頑張れる

という人に向けたアプリを目指します。

対象年齢はまだ検討中です。
中年期から将来のフレイル・障害・認知機能低下を遅らせるために何が有効か、研究を確認しながら決めていきます。

## デザイン原則

FutureLift は、健康不安を煽るアプリにはしません。

- **加点のみ。減点しない**
- できなかった日を責めない
- 連続記録が途切れても罰しない
- 「介護が必要 = 本人の努力不足」と扱わない
- 根拠の弱い健康情報を断定しない
- 自分のためだけでなく「誰かの役に立った」という達成感を返す
- 少し思想は強い。でも説教臭くしない

を大切にします。

## エビデンスについて

FutureLift は、介護予防・Healthy Ageing・中年期からのフレイル予防に関する研究をもとに機能を設計します。

調査の起点として、以下のような資料を参照しています。

- NICE: *Dementia, disability and frailty in later life – mid-life approaches to delay or prevent onset*（40〜64歳を対象とするガイドライン）
- WHO: *Healthy Ageing / Functional Ability*
- 厚生労働省: 介護予防に関する資料・身体活動ガイド
- 中年期の修正可能なリスク要因と後年のフレイルを扱うシステマティックレビュー・コホート研究

今後、各機能について「何を目的とするか」「どの程度の根拠があるか」を整理していきます。

## 構想中の機能

- スクワットなどの筋トレ記録
- 運動時に若者キャラクターが拍手・感謝する演出
- 社会貢献ポイント
- 将来の介護・社会保障負担への影響を示す推計表示
- 趣味・社会参加・外出などの活動記録
- 老後の自立に関する短いコラム／マガジン
- エビデンスと出典の表示
- 国ごとの制度・統計に合わせたローカライズ
